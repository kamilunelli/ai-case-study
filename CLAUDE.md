# Instruções para o Claude Code

Este repositório é um trabalho acadêmico. Siga as regras conforme o tipo de tarefa.

## 1. Mensagens de coleta

Se a mensagem começar com "Resolva o problema a seguir em Python 3":

- Resolva o problema e salve **apenas o código** no caminho indicado na própria mensagem
  (sempre `solucoes/claude/pXX.py`).
- **Não leia nenhum outro arquivo do repositório** (nem este contexto em `docs/`, nem outras soluções).
- Não execute, não teste e não pesquise na internet.
- Não crie nenhum outro arquivo e não altere arquivos existentes.
- Se o arquivo de destino já existir, **não sobrescreva**: avise e pare.

## 2. Qualquer outra tarefa

Antes de qualquer outra tarefa (validar dados, rodar a análise, escrever o artigo, slides etc.),
leia `docs/contexto.md` e siga as regras de lá.

## 3. Regras permanentes

- Nunca altere, corrija ou reformate arquivos já existentes em `solucoes/`. São dados brutos.
- Nunca crie arquivos em `solucoes/gemini/`.
- Nunca invente dados ou resultados.
